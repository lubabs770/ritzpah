# The prompt that summoned GitHub Dark Dimmed

RITZPAH_SKILL.md requires every theme to record the exact words that asked for
it. These are those words, unedited — typos included, because a prompt that has
been tidied up is no longer the prompt.

## The request

> use the ritzpah skill, here is my prompt "make my machine be github!!!!,
> specificly the dark themes, in all it's ui nuance"

— Sam, 2026-08-25

## The two questions it took, and the answers

**Scope — which of GitHub's dark themes?**

> All five.

GitHub's Appearance settings offer five selectable dark themes; Primer publishes
eight dark variants in total, three of which the product does not expose. The
five selectable ones were built, and GitHub Dark Dimmed is one of them.

**Wallpapers — draw them, or fetch real GitHub assets?**

No option was picked. The note left instead:

> it can download when necessery, just saying.

Read as permission rather than instruction, which is how it was written. So the
wallpapers are drawn from Primer's own tokens — GitHub does not publish a
2560×1440 image of a contribution graph, and there was nothing to download that
would have been more faithful than deriving it. The one thing that *was* fetched
is real: [@primer/octicons](https://github.com/primer/octicons) 19.33.0, MIT,
© GitHub Inc., unpacked from npm and drawn as vector paths. Those are GitHub's
actual icons, not redrawings of them.
